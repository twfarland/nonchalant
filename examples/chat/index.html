Chat (client-server over the wire)

How it works

Each room is one process on the server, spawned the first time anyone looks its name up and evicted after an hour idle. A suspended generator is kilobytes, so one node process holds thousands of rooms — the registry, not your code, is the room lifecycle.

export const room = async function* (self) {
  let lines = []
  yield { lines }
  for await (const msg of self) {
    lines = [...lines.slice(-49), { id: nextId++, from: msg.from, text: msg.text }]
    yield { lines }
  }
}

// every tab, any room:
conn.lookup('room', { name })   // same name, same process, at any distance

Posts are casts; history arrives as patches. Kill the server mid-conversation: readers keep the last history with stale set, and the reconnecting transport re-looks-up when it returns.
