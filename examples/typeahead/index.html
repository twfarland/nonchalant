Typeahead

How it works

self.latest() is the entire debounce/race/cancel story: while a search is in flight the loop is not listening, and when it finishes it resumes at the newest query, skipping every stale keystroke in between. The abort signal cancels in-flight work if the process is disposed.

for await (const { q } of self.latest()) {
  yield { q, results, pending: true }
  try {
    results = await api.search(q, { signal: self.signal })
    yield { q, results, pending: false }
  } catch { /* aborted or failed; the loop simply continues */ }
}
