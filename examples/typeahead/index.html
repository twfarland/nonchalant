Typeahead

How it works

self.latest() conflates queued input: while a search is in flight the loop is not listening, and when it finishes it resumes at the newest query, skipping every intermediate keystroke. It does not cancel the active search; the abort signal cancels that work only if the process is disposed.

for await (const { q } of self.latest()) {
  yield { q, results, pending: true }
  try {
    results = await api.search(q, { signal: self.signal })
    yield { q, results, pending: false }
  } catch {
    // aborted or failed; the loop simply continues
  }
}
