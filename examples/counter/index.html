Counter

How it works

This is the whole app. cell(0) is five lines of sugar over spawn — a process whose messages are its next values — and a process is already a valid slot, so span({}, count) is a live binding. The function runs once; there is no re-render.

function Counter(): VNode {
  const count = cell(0)
  return div({ class: 'card' },
    button({ onclick: () => count.send(count() - 1) }, '-'),
    span({ class: 'value' }, count),
    button({ onclick: () => count.send(count() + 1) }, '+'))
}
