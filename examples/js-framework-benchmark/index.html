How it works

The standard krausest benchmark table: one state process, one keyed thunk hole. Selection is its own process, so selecting a row wakes exactly two rows — the old and the new — not the table.

tr({ key: row.id, class: () => (selected() === row.id ? 'danger' : '') },
  td({ class: 'col-md-1' }, String(row.id)),
  td({ class: 'col-md-4' },
    a({ onclick: () => selected.send(row.id) }, row.label)),
  // ...
)
