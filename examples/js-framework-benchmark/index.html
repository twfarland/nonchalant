How it works

The standard krausest benchmark table: one state process, one keyed thunk hole. Selection is its own process yielding { [id]: true }; each row reads only its own entry, so selecting a row wakes exactly two rows — the old and the new — not the table. bench.test.ts holds every operation to a count budget: a swap is two DOM moves, a select two attribute writes.

tr({ key: row.id, class: () => (selected()[row.id] === true ? 'danger' : '') },
  td({ class: 'col-md-1' }, String(row.id)),
  td({ class: 'col-md-4' },
    a({ onclick: () => selected.cast({ type: 'select', id: row.id }) }, row.label)),
