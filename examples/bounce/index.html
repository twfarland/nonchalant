Bounce (one process, two renderers)

How it works

One physics process, two renderers reading the same yields. The left panel is the DOM sink — keyed divs with style bindings. The right is a canvas redrawn by one tracked effect. Retargeting isn't a feature; a renderer is just another reader.

// the canvas "sink" is one effect
effect(() => {
  const { balls } = sim()
  ctx.clearRect(0, 0, W, H)
  for (const b of balls) drawBall(ctx, b)
})
