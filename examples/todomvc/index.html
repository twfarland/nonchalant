TodoMVC

How it works

One process owns the state: messages in, one immutable yield per message. The generator body is the reducer — no actions, no dispatch table, just a loop.

for await (const msg of self) {
  switch (msg.type) {
    case 'add':    todos = [...todos, { id: nextId++, title: msg.title, done: false }]; break
    case 'toggle': todos = todos.map((t) => t.id === msg.id ? { ...t, done: !t.done } : t); break
    // destroy / toggle-all / clear-completed / filter ...
  }
  yield { todos, filter }
}

The list is a keyed thunk hole: toggling a todo patches exactly one row; every other node sleeps. The process lives in todos.ts, where its tests drive the generator directly — message in, yield out — with no runtime or DOM (see docs/testing.md).
