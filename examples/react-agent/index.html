An agent, in React — React draws it; processes run it

How it works

This is the agent demo's process tree — the agent loop, its tools, the approval gate, the durable journal — imported unchanged and rendered by React instead of by nonchalant's own DOM sink. Ask about a process or a patch, give it arithmetic, or say refund 20 and it waits for you.

Components read processes through @nonchalant/react. useDerive runs its function inside a derive, so a component subscribes to exactly the paths the function read. The transcript renders one memoised row per step; a streamed word re-renders the streaming line and nothing else.

const Turn = memo(function Turn({ agent, at }: { agent: Agent; at: number }) {
  const step = useDerive(() => agent()?.steps[at], [agent, at])
  // …render one row
})

The gate is a process

The agent's refund call is an ordinary call() that the approval process does not answer until somebody decides. The panel is a view of its queue, and the buttons are casts:

function Approvals({ queue }: { queue: Process<ApprovalState | undefined, ApprovalMsg> }) {
  const asking = useDerive(() => queue()?.pending[0], [queue])
  if (asking === undefined) return null
  const decide = (ok: boolean) => (): void => queue.cast({ type: 'decide', ok })
  // …approve / refuse buttons calling decide(true) / decide(false)
}

Killing the machine

useLookup keeps the agent's registry entry alive while the page shows it, and looks it up again if it is evicted. kill the machine evicts it; the page re-renders, the lookup activates a new process, and durable() rehydrates it from the journal — mid-question if that is where it was.

// parts.ts
agent: () => brain.lookup('agent', { id: 'demo' }),
kill: () => brain.evict('agent', { id: 'demo' }),

// app.tsx
const agent = useLookup(parts.agent)

The page runs under StrictMode. The test (react-agent.test.tsx) drives it end to end with a scripted model: the stream, the tool row, the gate, and the rehydration.
