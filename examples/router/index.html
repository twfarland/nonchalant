Router (+code splitting)

How it works

Built on examples/lib/router.ts (~40 lines of userland): the route is a process, link() returns spreadable anchor attrs, and navigation uses location.replace by default — browsing around doesn't pile up back-button history.

Pages are view processes. Navigating disposes the outgoing page — its whole scope, page-local state included — yields a loading state, awaits the import() (that's the code splitting), and yields the new page.

for await (const route of router.route) {
  current?.[Symbol.dispose]()          // the outgoing page's scope ends here
  if (route === 'about') {
    yield Shell(Spinner())             // interim yield: the loading state
    const { AboutView } = await import('./about.ts')
    current = spawn(AboutView, undefined)
  } else {
    current = spawn(HomeView, undefined)
  }
  yield Shell(current)                 // a view process is a valid slot
}
