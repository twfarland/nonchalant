Shared cart (the pitch demo)

How it works

The pitch. The cart process never knew which side of the wire it runs on, so moving its state to a server is choosing a different registry — one line:

const shop = registry({ cart: define(cart) })                             // this tab
// const shop = connect<Shop>(webSocketTransport('ws://127.0.0.1:4321/?token=alice-demo-token'))  // the server

Same messages, same call(), same fine-grained updates either way. Run pnpm cart-server, flip the line, and a disconnect leaves readers on the last value with stale set until the transport finds the server again.

The cart itself is written with reducer, optional sugar for a process that only folds messages into state. It compiles to an ordinary generator process, which is why the registry and the wire need nothing special for it:

export function cartStep(s: CartState, msg: CartMsg): CartState {
  switch (msg.type) {
    case 'add':
      return priced([...s.items, msg.item])
    // …
    case 'checkout':
      msg.reply({ ok: true, charged: s.total })
      return s.items.length === 0 ? s : priced([])  // same state: no yield
  }
}

export const cart = reducer((_: { userId: string }) => priced([]), cartStep)
