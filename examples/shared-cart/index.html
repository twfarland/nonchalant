Shared cart (the pitch demo)

How it works

The pitch. The cart process never knew which side of the wire it runs on, so moving its state to a server is choosing a different registry — one line:

const shop = registry({ cart: define(cart) })                             // this tab
// const shop = connect<Shop>(webSocketTransport('ws://127.0.0.1:4321/'))  // the server

Same messages, same call(), same fine-grained updates either way. Run pnpm cart-server, flip the line, and a disconnect leaves readers on the last value with stale set until the transport finds the server again.
